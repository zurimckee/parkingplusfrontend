# 🅿️ SmartParkingPlus - Frontend

**Live Demo:** [SmartParkingPlus App](https://smartparkplusapp.vercel.app/)

## 🚀 Project Overview

Smart Parking Plus is built to solve the hassle of finding and managing parking spaces. This frontend application provides a seamless, responsive interface for users to interact with real-time parking data and view availability.

### Key Features
*   **Real-time Availability:** Constantly accurate spot display, updating data every sixty seconds
*   **Responsive Design:** Fully optimized for mobile and desktop viewing.
*   **Interactive Maps:** Visual representation of parking locations.
*   **Parking Lot Navigation:** Easy to find buttons providing directions to each parking space 


Created using React(Vite), Javascript, Node/Express, Deployed using Vercel
